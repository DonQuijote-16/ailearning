# AI 学习总览大纲

个人向学习路线图入口文档：说明学什么、按什么顺序学、每一阶段侧重哪些能力，以及建议的自检与产出。后续可在此仓库中补充周计划、笔记与练习代码；本文件会随进度迭代更新。

---

## 学习目标

- **编程与工具**：打牢 Python 基础，熟悉常用科学计算与 ML 库、环境与版本管理。
- **数学与直觉**：补齐支撑经典机器学习所需的线性代数、概率与优化直觉（够用即可，随用随补）。
- **经典机器学习**：理解常见模型、训练/验证流程与过拟合等基本问题。
- **深度学习**：从神经网络基础到常见架构（如 CNN、序列模型），能读论文与跑通教程级项目。
- **大模型与应用**：理解 Transformer/LLM 基础、提示与简单应用开发，建立 responsible use 意识。

---

## 分阶段路线图

### 阶段 0：环境与 Python 基础

- **核心主题**：Python 语法与数据结构、函数与模块、`venv`/依赖管理、基础调试与读写文件。
- **侧重技能**：能独立写小脚本、读报错、用第三方库。

### 阶段 1：数学与数值直觉（精简）

- **核心主题**：向量与矩阵、梯度与简单优化；概率基础（期望、条件概率、常见分布直觉）。
- **侧重技能**：能对照公式阅读入门级 ML 教材与代码中的矩阵运算。

### 阶段 2：经典机器学习

- **核心主题**：监督学习流程（数据划分、特征、指标）；线性模型、树模型与集成；简单无监督概念（如聚类）。
- **侧重技能**：用库完成端到端小项目，能解释验证集作用与常见陷阱。

### 阶段 3：深度学习入门

- **核心主题**：张量与自动微分；MLP；反向传播直觉；用一种框架完成图像或序列入门教程。
- **侧重技能**：能改官方示例、观察 loss/曲线、做简单消融。

### 阶段 4：LLM 与应用向

- **核心主题**：注意力与 Transformer 梗概；API/开源模型使用；RAG、Agent 等概念级了解；隐私与安全基础。
- **侧重技能**：能搭建最小可用 demo，并意识到边界与评测的重要性。

## 各阶段建议产出与自检

以下为可勾选清单，便于对照进度（复制到个人笔记或 issue 中勾选即可）。

### 阶段 0

- [ ] 完成一个「纯 Python」小项目（如 CLI 工具或数据处理脚本）
- [ ] 能说明 `venv` 与 `pip`/`uv` 等你所选工具的基本用法

### 阶段 1

- [ ] 手算或代码验证过至少一个小例子（如二维梯度下降）
- [ ] 能用自己的话解释训练误差与泛化误差为何可能不同

### 阶段 2

- [ ] 跑通一个完整的 sklearn（或同类）分类/回归流程（含划分验证集）
- [ ] 尝试过至少一种特征或模型超参的简单对比

### 阶段 3

- [ ] 跑通官方或教程中的 CNN 或 RNN/Transformer 入门 notebook
- [ ] 能修改 batch size 或学习率并观察现象

### 阶段 4

- [ ] 完成一个调用 LLM API 或本地推理的最小应用（如问答或摘要）
- [ ] 列出你认为该 demo 的三个主要局限或风险点
